# DiscordThemes
Original recreations with a hint of looks from ClearVision, so credits go 100% to them, also this JS script you find here is to make the themes screensaver and loadingscreen override discord default loading screen and add a fresh new feature that is the screensaver, you can customise them if you want to or you can copy some stuff and make your own.

is recommended to use better discord for these themes, but you can also use vencord.

if you use vencord the process of making a plugin that only you can use is hard as hell so i really do recommend BetterDiscord as its easier and better.

First open better discords Plugin folder and open it in Vs code or WebStorm by Jet Brains, then click File/save or save as if its new.
you may have to keep trying to do this as sometimes it bugs to add to BetterDiscord. it works for me so it will for you, please don't complain, also you must know what you are doing as well.

i will also be updating these themes a lot so stay tuned for new versions, i will post these for now on, https://themes.equicord.org/
so stay tuned.

for the themes, go to user settings in discord scrolldown the sidebar, and you can see custom CSS, paste any of the themes you se here into it.
